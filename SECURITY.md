---

## Reporting a Vulnerability

As space station software operating in an isolated habitat network, security and supply-chain integrity are paramount.

If you identify a security flaw, vulnerability, or potential exploit:

1. **Do NOT open a public GitHub issue.**
2. Send an encrypted email with reproduction steps and diagnostic logs to:
   - `ai-security@isro.gov.in`
   - `flight-software-ciso@isro.gov.in`
3. Include:
   - Affected subsystem (`backend`, `ai`, `hardware`, `frontend`)
   - Severity assessment (CVSS score)
   - Step-by-step reproduction guide

The security review team will acknowledge your report within **12 hours** and provide remediation tracking updates.
